# Minecraft Stats Site
1. Create a GitHub repo and upload everything in this folder.
2. Repo → Settings → Secrets and variables → Actions → add:
   - `EXAROTON_TOKEN` (exaroton.com/account → API token)
   - `EXAROTON_SERVER_ID` (from your server's URL/API)
3. Settings → Pages → Deploy from branch → `main` / root.
4. Actions tab → "Update stats" → Run workflow.
